What it is for

The money math behind a points currency in a rewards app, site, game or community, done with integers so every amount is exact.

  • Credit points for an offer

    Turn an offer payout in dollars into points with your rate, user share and bonus. The amount is rounded once, so the same payout always credits the same points.

  • Reverse what was credited

    When an offer is reversed, take back the stored credit and nothing else, with a negative balance or a stop at zero and the uncollected rest reported.

  • Cash-outs and inflation

    Price a reward in points, check the minimum and the balance, and see when a bonus or a cheap shop rate hands users more than the offers earned.

Why integers

Floating point loses a unit on ordinary amounts. The kit keeps money and points as integers and rounds once, so a credit and its reversal always match.

Use it in your project

      
Amounts are integers end to end: micro-dollars for money, units for points. The JavaScript and PHP versions return the same results, and both pass the same {{VECTOR_COUNT}} shared test vectors.

    

    

      

        
        
      

      

        

          
Install (Node 20+)

          
npm install @moonetix/reward-economy-kit

        

        

          
Credit, reverse, check

          
import { defineCurrency, parseUsd, pointsForPayout, applyReversal, inflationCheck, formatUnits } from '@moonetix/reward-economy-kit';

const coins = defineCurrency({ rate: '1000', userShareBps: 6000 });   // 1000 coins per $1, 60% to users

const credited = pointsForPayout(parseUsd('0.85'), coins, { bonusBps: 1000 }); // 561n = 0.85 x 1000 x 60% x 110%
formatUnits(credited, coins.decimals);                                       // "561"

applyReversal({ balance: 400n, credited });
// { reversed: 561n, newBalance: -161n, uncollected: 0n }

inflationCheck(coins, { bonusBps: 1000 }).effectiveUserShareBps;            // 6600n

Credit and reverse

          
require 'vendor/autoload.php';

use Moonetix\RewardEconomy\RewardEconomy as Rewards;

$coins = Rewards::defineCurrency(['rate' => '1000', 'userShareBps' => 6000]);

$credited = Rewards::pointsForPayout(Rewards::parseUsd('0.85'), $coins, bonusBps: 1000); // 561
Rewards::applyReversal(balance: 400, credited: $credited);
// ['reversed' => 561, 'newBalance' => -161, 'uncollected' => 0]
